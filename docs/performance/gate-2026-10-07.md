# The first performance gate run, 2026-10-07

On this machine (Windows 10, the CPU named below), `benchmark --quick` at the Phase 10 checkpoint (`23b6c56`, before Phases 11-16) and at this branch, back to back.

1. **It failed**: the PDF export of 500 blocks took 0.640 s against 0.385 s (+66%). Profiling showed the FontResolver (FONT-002, Phase 11) looking up the script of every character of every run, 249,000 times for 500 blocks.
2. **Fixed**: the script lookup is cached per character (`translation/language.py`) and the resolver returns one run at a glance when the paragraph's font draws every character and they are of one script (`export/font_resolver.py`, equivalent to the full walk: `test_multilingual.py`).
3. **The run after the fix, below: passed.** (The base ran one repeat -- its benchmark ignored `--repeats` with `--quick` -- the current three.)
